# سرویس‌یار گلدرانی

اپلیکیشن اندروید مدیریت خدمات آسانسور، با ذخیره‌سازی محلی روی دستگاه و بدون نیاز به اینترنت برای کارهای روزمره.

## امکانات
- ورود اولیه با نام کاربر و شماره تماس
- صفحه اصلی با پیام خوش‌آمدگویی
- ثبت، نمایش و حذف سرویس‌ها
- ثبت، نمایش و حذف ساختمان‌ها
- ثبت، نمایش و حذف طلب‌ها
- تنظیمات حالت روز/شب و اندازه نوشته‌ها
- تأیید حذف با نام کاربر
- تماس با پشتیبانی: 0912-468-2580
- ساخت APK با GitHub Actions

## ساخت APK از GitHub
1. تمام محتویات ZIP را در ریشه مخزن GitHub آپلود کنید (فایل `.github/workflows/build-apk.yml` نیز باید آپلود شود).
2. به بخش **Actions** مخزن بروید.
3. workflow با نام **Build Goldarani APK** را انتخاب کنید.
4. روی **Run workflow** بزنید یا پس از push منتظر اجرای خودکار بمانید.
5. پس از سبز شدن اجرا، در پایین صفحه بخش **Artifacts**، فایل `GoldaraniService-debug-apk` را دانلود کنید.
6. ZIP دانلودشده را باز کنید؛ فایل `app-debug.apk` داخل آن است.

## نکته
این پروژه سورس برنامه است، نه APK از پیش ساخته‌شده. APK در GitHub Actions ساخته می‌شود. برای نصب روی گوشی، فایل APK را به گوشی منتقل و نصب از منبع مورد اعتماد را مجاز کنید.
